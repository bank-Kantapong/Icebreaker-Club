# Product Specification — Icebreaker Club

## 1. ภาพรวมผลิตภัณฑ์ (Product Overview)

**Icebreaker Club** (ชื่อโปรเจกต์ชั่วคราว สามารถเปลี่ยนผ่าน `src/lib/brand.ts` ได้ทันที) คือเว็บเกมไพ่ชวนคุย (Icebreaking Card Game) แบบ 2 ภาษา (**ไทย / อังกฤษ**) ที่ออกแบบมาให้ผู้เล่นเปิดผ่านมือถือหรือหน้าจอเดียวเพื่อใช้เล่นร่วมกับเพื่อน คนรัก คนรู้จักใหม่ หรือกลุ่มสังสรรค์ โดยไม่ต้องสมัครสมาชิก ไม่ต้องดาวน์โหลดแอป และไม่มีค่าใช้จ่ายใด ๆ

### คุณค่าหลัก (Core Value Proposition)
- **เข้าถึงทันทีแบบ Minimal UX (Zero Friction)**: เปิดเว็บเห็นขั้นตอนสั้น ๆ 3 ขั้นตอนด้านบนสุด พร้อมปกสำรับไพ่ทั้ง 3 กองที่แตะเริ่มเล่นได้ทันทีโดยไม่ต้องอ่านข้อความยาว ๆ
- **รองรับ 2 ภาษาเต็มรูปแบบ (`TH | EN`)**: สลับภาษาไทยและอังกฤษได้ทันทีจากแถบด้านบน ทั้งข้อความ UI ชื่อสำรับ และคำถามบนไพ่ครบทั้ง 96 ใบ
- **ออกแบบเพื่อบทสนทนาจริงและปลอดภัย**: ข้ามไพ่ได้ทุกใบ ไม่บังคับเปิดเผยความลับ และกองไพ่ปาร์ตี้รองรับผู้ไม่ดื่มแอลกอฮอล์เสมอ
- **บันทึกรูปการ์ดคำถามไปชวนคุยต่อบนโซเชียล**: สามารถกดบันทึกรูปภาพการ์ดคำถามขนาด Story (`1080×1920`) ที่คลีนและอ่านง่าย เพื่อนำไปโพสต์ชวนเพื่อนคุยต่อบน IG Story หรือโซเชียลมีเดียได้ทันที
- **ฟรี 100%**: ไม่มี Paywall ไม่มีโฆษณาคั่น ไม่ใช้ AI API ระหว่างเล่น และโฮสต์บนบริการ Free Tier ได้เต็มรูปแบบ

## 2. กลุ่มเป้าหมายและกองไพ่ใน MVP (Decks Scope)

มี 3 กองไพ่หลัก กองละ 32 ใบ (รวม 96 ใบ ไม่ซ้ำกัน เก็บในรูปแบบไฟล์ JSON 2 ภาษาภายใต้ `src/content/data/`):

### A. Get to Know (`get-to-know`) — ทำความรู้จัก / Get to Know
- **กลุ่มเป้าหมาย**: เพื่อนใหม่ เพื่อนร่วมงาน คนเพิ่งรู้จัก หรือกลุ่มเพื่อนที่อยากคุยเรื่องใหม่ ๆ
- **เนื้อหา**: อาหาร งานอดิเรก ความทรงจำวัยเด็ก มุมมองชีวิต และคำถามชวนคิดที่ไม่ล่วงล้ำความเป็นส่วนตัว
- **ระดับความเข้มข้น (Intensity)**:
  - `1` (อุ่นเครื่องสบาย ๆ / Easy Warm-up): คำถามเบา ๆ ตอบง่าย
  - `2` (เรื่องเล่าชวนคุย / Story Starters): คำถามเกี่ยวกับเรื่องราวและรสนิยม
  - `3` (มุมมองและแรงบันดาลใจ / Deeper Perspectives): คำถามสะท้อนความคิดและความฝัน

### B. Couples (`couples`) — คู่รักชวนคุย / Couples Edition
- **กลุ่มเป้าหมาย**: คนคุย คู่เดต คู่รักที่คบกันอยู่ หรือคู่ชีวิตที่อยากเติมความเข้าใจกัน
- **เนื้อหา**: ความประทับใจแรก ความทรงจำดี ๆ ภาษารัก แผนอนาคตร่วมกัน และกิจกรรมที่อยากทำด้วยกัน โดยไม่สร้างดราม่าหรือบังคับเปิดเผยความลับ
- **ระดับความเข้มข้น (Intensity)**:
  - `1` (น่ารักกุ๊กกิ๊ก / Sweet & Playful): ความชอบและโมเมนต์เล็ก ๆ ในชีวิตประจำวัน
  - `2` (เข้าใจกันมากขึ้น / Closer Connection): ความรู้สึกและการสื่อสารในความสัมพันธ์
  - `3` (หัวใจและอนาคต / Heart & Future): ความหมายของความรักและภาพอนาคตร่วมกัน

### C. Party & Drinks (`party-drinks`) — ปาร์ตี้ & ชนแก้ว / Party & Drinks
- **กลุ่มเป้าหมาย**: กลุ่มเพื่อนในงานปาร์ตี้ โต๊ะอาหาร หรือทริปท่องเที่ยว
- **เนื้อหา**: ภารกิจสั้น ๆ โหวตสนุก ๆ มินิเกมหน้าวง และการท้าทายขำ ๆ ที่อ่านเข้าใจได้ทันที
- **ความปลอดภัย**: รองรับการจิบน้ำ น้ำผลไม้ หรือทำท่าทางสนุก ๆ แทนการดื่มแอลกอฮอล์ ไม่สนับสนุนการดื่มหนักหรือเร็วเกินไป และไม่บังคับทำสิ่งที่ไม่ยินยอม
- **ระดับความเข้มข้น (Intensity)**:
  - `1` (อุ่นเครื่องหน้าวง / Party Warm-up): เกมไว ๆ เรียกเสียงหัวเราะเบา ๆ
  - `2` (โหวตฮาประจานเพื่อนรัก / Group Votes & Mini-Games): โหวตกลุ่มและภารกิจชวนฮา
  - `3` (ตัวตึงประจำวง / Ultimate Party Energy): ภารกิจสร้างสีสันและการแสดงออกสุดฮา

## 3. โครงสร้างข้อมูลไพ่ JSON (Bilingual Card Schema)

ไพ่แต่ละใบใน `src/content/data/cards/*.json` มีโครงสร้างข้อมูลดังนี้:
- `id`: รหัสไพ่ที่ไม่ซ้ำกันทั้งระบบ (`gtk-01`..`gtk-32`, `cpl-01`..`cpl-32`, `pty-01`..`pty-32`)
- `deckId`: รหัสอ้างอิงกองไพ่ (`get-to-know` | `couples` | `party-drinks`)
- `type`: ประเภทของไพ่ (`question` | `mission` | `vote` | `wildcard`)
- `prompt`: ข้อความคำถามหรือภารกิจแบบ 2 ภาษา (`{ th: string, en: string }`)
- `followUp` (Optional): คำถามต่อยอดหรือทางเลือกเสริมแบบ 2 ภาษา (`{ th: string, en: string }`)
- `illustration`: รหัสอ้างอิงภาพประกอบขาวดำที่มีอยู่จริงใน `src/content/data/illustrations.json` และ `public/illustrations/*.svg`
- `intensity`: ระดับความเข้มข้น (`1` | `2` | `3`)
- `tags`: ป้ายกำกับหมวดหมู่ย่อยของไพ่แบบ 2 ภาษา (`{ th: string[], en: string[] }`)

## 4. ประสบการณ์ผู้ใช้และหน้าจอ (User Flows & Screens)

### 4.1 แถบนำทางด้านบน (Header)
- แสดงโลโก้และชื่อแบรนด์ `Icebreaker Club`
- ปุ่มลัดกลับหน้าเลือกกองไพ่ (`เลือกกองไพ่` / `Decks`)
- ปุ่มสลับภาษา `TH | EN` (`LanguageSwitcher`) ที่เปลี่ยนภาษาทั่วทั้งแอปพลิเคชันทันที

### 4.2 หน้าแรก (Minimal Home Page — `/`)
- **HowToBanner**: แถบสรุปวิธีเล่น 3 ขั้นตอนสั้น ๆ ด้านบนสุด (`1 เลือกสำรับ → 2 แตะจั่วไพ่ → 3 ชวนคุยหรือข้ามได้ตลอด`)
- **Deck Cover Showcase**: แสดงสำรับไพ่ทั้ง 3 กองในรูปแบบปกสำรับไพ่ซ้อนกันที่มีมิติ (Tactile Deck Cover) เห็นภาพประกอบชัดเจนและแตะเพื่อเข้าสู่หน้าจั่วไพ่ (`/play/[slug]`) ได้ทันที

### 4.3 หน้ารายละเอียดกองไพ่และตั้งค่ารอบการเล่น (Deck Detail & Setup — `/decks/[slug]`)
- **DeckOverviewHero**: แสดงปกสำรับ จำนวนไพ่ จำนวนผู้เล่นที่แนะนำ คำอธิบาย ปุ่มเริ่มเล่นทันที และปุ่มแชร์ลิงก์กองไพ่
- **DeckSetupPanel**: ตัวเลือกกรองระดับความเข้มข้น (`รวมทุกระดับ` หรือเลือกระดับ `1`, `2`, `3`) พร้อมแสดงจำนวนไพ่ที่ตรงตามตัวเลือกแบบทันทีและปุ่มเริ่มเล่นตามระดับที่เลือก
- **DeckRulesCard**: แสดงขั้นตอนการเล่นและกติกามารยาทประจำวง

### 4.4 หน้าจอเล่นไพ่ (Playing Screen — `/play/[slug]`)
- **Physical Stacked Deck & Constant Card Height**:
  - แสดงสำรับไพ่ที่มีการ์ดซ้อนอยู่ด้านล่างตามจำนวนไพ่ที่เหลือ
  - ตัวการ์ดมีความสูงคงที่ (`h-97.5 sm:h-102.5`) เพื่อไม่ให้ปุ่มควบคุมด้านล่างกระโดดไปมาเมื่อเปลี่ยนใบ
  - ส่วนข้อความคำถาม (`card.prompt`) กำหนดให้แสดงผลไม่เกิน 4 บรรทัด (`line-clamp-4`) พร้อมจองพื้นที่คงที่
- **สถานะยังไม่เปิดไพ่ใบแรก (`PlayingCardBack`)**: แสดงหลังไพ่ลายพิเศษและปุ่มเปิดไพ่ โดยไม่เปิดเผยข้อความของไพ่ใบถัดไปล่วงหน้า
- **แอนิเมชันจั่วและหงายการ์ด (`PlayingCardFront`)**: เล่นแอนิเมชันจั่วไพ่และพลิกหงายการ์ดแบบ 3 มิติที่ลื่นไหล และลดทอนเป็น Fade นุ่มนวลเมื่อผู้ใช้ตั้งค่า `prefers-reduced-motion`
- **ปุ่มควบคุม (`GameControls`)**:
  - `เปิดไพ่ใบนี้` / `ไพ่ใบถัดไป →` / `สรุปจบรอบ →`
  - `ข้ามไพ่ใบนี้` (นำไพ่ออกจากกองรอบนี้โดยไม่นำกลับมาซ้ำ)
  - `↻ สับไพ่เริ่มรอบใหม่` (สับไพ่ทั้งหมดใหม่ทันทีโดยไม่ต้องรีโหลดหน้า)
  - `⬇ บันทึกรูปการ์ดคำถาม` (`ShareCardStoryButton`): แสดงเมื่อเปิดหน้าไพ่ เพื่อสร้างและดาวน์โหลดรูปภาพการ์ดคำถามขนาด `1080×1920` (มีเฉพาะภาพประกอบและข้อความคำถามที่ตัดบรรทัดพอดีกรอบ พร้อมชื่อสำรับด้านบนและด้านล่าง) สำหรับนำไปโพสต์ลง IG Story หรือโซเชียลมีเดีย
- **หน้าจอจบรอบ (`RoundCompleteView`)**: เมื่อเปิดครบทุกใบในรอบ จะแสดงสรุปจำนวนไพ่ที่เล่นไปแล้ว จำนวนไพ่ที่ข้าม และปุ่มสับไพ่เริ่มรอบใหม่หรือกลับไปเลือกกองไพ่อื่น
